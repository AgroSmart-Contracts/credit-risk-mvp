Counterparty risk formula — test results

Applied to all real deals in full-deals-dataset.csv that have both buyer and supplier years-in-business populated (45 deal rows, grouped into 7 counterparty relationships).

Methodology

  • Base score = (buyer years × 10, capped 100) × 0.6 + (supplier years × 10, capped 100) × 0.4
  • Execution adjustment = +10 if the deal reached full milestone approval (currentMilestone = 7), +0 if it stalled earlier
  • Track-record bonus = +5 per prior deal between the exact same buyer + supplier pair
  • Coface bonus = 0 (field is blank on every row currently)
  • Final score = base + execution adjustment + track-record bonus, capped between 0 and 100
